# Font licenses

The field guide bundles three typefaces. All three allow redistribution; their notices are reproduced here as the licenses require.

| Files | Typeface | License |
|---|---|---|
| `Charter-*.otf` | Bitstream Charter | Bitstream Charter license (below) |
| `TeXGyreHerosCn-*.otf` | TeX Gyre Heros Condensed | GUST Font License (below) |
| `DejaVuSansMono.ttf` | DejaVu Sans Mono | Bitstream Vera license, with DejaVu changes in the public domain (below) |

The Charter files were converted from Bitstream's Type 1 release (`bchr8a`, `bchri8a`, `bchb8a`, `bchbi8a`) to OpenType CFF, keeping the original outlines, widths and kerning, with the no-break space mapped to Charter's space glyph. The Heros and DejaVu files are unmodified.
